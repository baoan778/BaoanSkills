# Code of Conduct

## Our standard

Be respectful, precise, and constructive. Assume good intent while requiring
evidence for security claims. Disagreement about technical conclusions is
welcome; harassment, discrimination, doxxing, and encouraging unauthorized
access are not.

## Expected behavior

- Respect scope, authorization, privacy, and disclosure timelines.
- Redact credentials, personal data, and unnecessary target details.
- Give credit to original authors and preserve license information.
- Accept maintainer decisions about provenance and release safety.

## Unacceptable behavior

- Publishing private data, live credentials, or unpatched exploit details.
- Encouraging or normalizing unauthorized testing.
- Plagiarism or removing copyright and license notices.
- Harassment, threats, or discriminatory language.

Maintainers may edit, reject, or remove contributions that violate this policy.
Report conduct concerns privately using the contact process described in
[SECURITY.md](./SECURITY.md).
